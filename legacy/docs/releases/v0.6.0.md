# Spawned v0.6.0

This release adds actor lifecycle building blocks and optional framework metrics,
and fixes shutdown races found during concurrency and backend research. The
framework still keeps concurrency machinery outside ordinary business handlers.

## Framework metrics

Opt into `spawned-concurrency`'s `metrics` feature for mailbox depth, sampled queue
wait and handler/request duration, request outcomes, actor exits and delivery
accounting. Collection has fixed aggregate series, no actor/message labels and
no exporter callbacks or network I/O. Timing can be full, sampled or disabled.
The default build compiles collection out. Pull snapshots or Prometheus text from
your own exporter task. See [metrics usage](../../../docs/GUIDE.md#metrics) and the
[overhead report](../../research/framework-metrics/2026-11-06/README.md).

## Lifecycle and shutdown

Actor identities and type-erased child handles support monitoring and links across
execution modes. `start_linked` installs the relation before child dispatch;
`trap_exit` and `#[exit_received]` allow an actor to observe linked exits. Runtime
shutdown closes links and accounting even before the first actor poll.

Thread actors now wake directly on cancellation. A single callback handles local
stop, child handles, linked exits and framework cleanup; repeated stops cannot
fill the mailbox with duplicate shutdown controls. This release also fixes idle
stop/dispatch races, reserved message publication at shutdown, monitor waiter
retention and completion-versus-destruction ordering.

See the [API guide](../../../docs/GUIDE.md#links-and-trapped-exits),
[link review](../reviews/pr-166-links.md) and
[external-contribution security review](../reviews/pr-168-security.md).

## Backend research

The repository includes reproducible throughput/latency, actor-graph, overload,
fairness, profiling, pinned-core and communicating-runtime studies with raw data
and graphs. These experiments inform backend choice; they do not select a single
winner for every application. Tokio remains the supported default. Private
experimental features are not a stable backend API and are not promoted by this
release. Read the [backend guide](../BACKENDS.md).

## Upgrade notes

All three library crates use version 0.6.0. Existing handler/protocol signatures
are unchanged. Metrics require explicit feature selection. Synchronous actors do
not require an active async executor but still depend on Tokio synchronization
through `spawned-rt`.

Stop and linked Kill remain cooperative; running blocking code is not preempted.
Caller timeout or dropping a reply receiver does not cancel accepted actor work.
Enqueue success is not a handling/durability guarantee. Links are building blocks:
automatic supervision/restarts, persistence and transparent reference replacement
are not implemented by this release. `ExitReason::Shutdown` is reserved.
