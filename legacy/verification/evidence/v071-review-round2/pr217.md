## macOS coordinator failure

On Apple Silicon, Rust 1.93.0, the full unmodified library run reproduced:

```text
system::coordinator_tests::coordinator_fault_stops_all_targets_and_retains_owned_cleanup
assertion failed: report.coordinator_failures.iter().any(|e|
    e.contains("injected system coordinator fault"))
169 passed; 1 failed; 1 ignored
```

The injected coordinator panic occurred, but its diagnostic had not yet reached
the report snapshot when the 30ms caller deadline expired under full-suite load.
No shared global fault flag caused this failure. The test now refreshes the
pending report until the diagnostic is visible under its existing 10-second
outer bound. Each iteration explicitly sleeps before a zero-deadline refresh,
so an immediately ready/closed-watch regression cannot prevent the timeout from
being polled. It still checks two stopped workers, retained control-runtime
ownership, incomplete cleanup until release, and final successful cleanup with
bounded failure diagnostics. The shutdown deadline was not enlarged.
